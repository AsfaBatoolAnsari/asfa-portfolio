# Design images go here

Drop one image per design in this folder, named to match its `image` field
in `src/data/portfolio.js` — no code edit needed.

```

mobile-dashboard.jpg
liquide-loading-animation.jpg
carousel-animation.jpg
car-animation.jpg

food-shop.jpg

mobile-app-wireframes.jpg
sweet-store.jpg
```

Any common image format works (.jpg, .png, .webp) — if you use a different
extension, just update that design's `image` field in `portfolio.js` to
match the actual filename.
